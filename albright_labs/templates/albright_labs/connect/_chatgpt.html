ChatGPT connects to outside services as a plugin. You won't copy a key - ChatGPT sends you to a page here to approve it.

  1. On a computer, open ChatGPT on the web and go to chatgpt.com/plugins.
  2. Click the + button, then Add custom MCP server.
  3. Name it Albright Labs. Under Connection, paste this as the Server URL: {% include "albright_labs/connect/_copy.html" with value=links.mcp id="chatgpt-mcp" %}
  4. For Authentication, choose OAuth.
  5. Read the warning, confirm it, click Create as a plugin, then install the plugin.
  6. ChatGPT opens a page on this site. Sign in if asked, choose Full access or Read only, and click Approve.
  7. In a chat, type @ and pick Albright Labs. The first time, paste the instructions below into the chat.

Don't see Add custom MCP server? Your ChatGPT plan or workspace doesn't offer it yet - use the Other / any AI tab instead.
Custom GPTs: OpenAI no longer lets personal accounts make new custom GPTs and retires them on December 11, 2026, so we don't recommend them. If you already have one with Actions: Import from URL {% include "albright_labs/connect/_copy.html" with value=links.openapi id="chatgpt-openapi" %} then Authentication: API Key, Auth Type: Bearer, and paste a key made below.
