Claude connects through a custom connector. You won't copy a key - Claude sends you to a page here to approve it.

  1. Open Claude on the web (claude.ai) or the Claude desktop app, and go to Customize › Connectors.
  2. Click Add, then Add custom connector.
  3. Name it Albright Labs and paste this as the remote MCP server URL, then click Continue: {% include "albright_labs/connect/_copy.html" with value=links.mcp id="claude-mcp" %}
  4. Keep the sign-in settings Claude marks Detected and click Add.
  5. Click Connect. Claude opens a page on this site: choose Full access or Read only and click Approve.
  6. In a chat, click + › Connectors and make sure Albright Labs is on.
  7. Make a Project and paste the instructions below into its project instructions (or into your profile's personal preferences), so Claude always knows them.

Once added, it works in Claude on the web, the desktop app and the mobile app. The Free plan allows one custom connector. On a Team or Enterprise plan, an Owner adds it first under Organization settings › Connectors; then you click Connect.
Claude Code: run claude mcp add --transport http albright-labs {{ links.mcp }}, then /mcp to sign in - or add --header "Authorization: Bearer YOUR_KEY" with a key made below in place of YOUR_KEY.
