{# Anthropic's steps - checked against platform.claude.com/docs (get-api-key, API overview, billing), Nov 2026. #}
  1. Go to the Claude Console and sign in or create an account.
  2. Add a payment method and buy credits on the Billing page ("Buy credits"). This is separate from a Claude Pro or Max subscription - you pay per use, usually cents per chat.
  3. Recommended: set a monthly limit on the Spend limits page.
  4. Create a key on the API keys page ("Create key"). Pick a workspace for it (the default one is fine) and copy the key - it's shown only once. It starts with sk-ant-.
  5. Paste it below and press Connect.
