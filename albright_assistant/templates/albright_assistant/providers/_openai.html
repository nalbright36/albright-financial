{# OpenAI's steps - checked against developers.openai.com (keys, billing, spend limits), Nov 2026. #}
  1. Go to the OpenAI developer platform and sign in or create an account.
  2. Add a payment method and buy credits on the Billing page. This is separate from a ChatGPT Plus or Pro subscription - you pay per use, usually cents per chat.
  3. Recommended: set a monthly spending limit on the Limits page (Edit spend limit under Spend).
  4. Create an API key on the API keys page ("Create new secret key") and copy it - it's shown only once. It starts with sk-.
  5. Paste it below and press Connect.
