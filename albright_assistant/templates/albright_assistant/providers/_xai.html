{# xAI's steps - checked against docs.x.ai (Responses API, models, console billing), Nov 2026. #}
  1. Go to the xAI Console and sign in or create an account.
  2. Buy prepaid credits on the Billing page (API spend management). This is separate from a SuperGrok or X Premium subscription - you pay per use, usually cents per chat.
  3. Recommended: keep the "Invoiced spending limit" at $0 (on the same Billing page, under API Credits). Then you can never spend more than the credits you bought.
  4. In the console, open API Keys, press "Create API Key" and copy it - it's shown only once. It starts with xai-.
  5. Paste it below and press Connect.
