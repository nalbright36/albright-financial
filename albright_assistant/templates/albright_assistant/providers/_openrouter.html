{# OpenRouter's steps - checked against openrouter.ai/docs (OpenAI-compatible API, keys, credits, limits), Nov 2026. #}
  1. Go to OpenRouter and sign in or create an account. One account reaches models from many companies.
  2. Buy credits on the Credits page. This is separate from any ChatGPT, Claude or Grok subscription - you pay per use, usually cents per chat (plus OpenRouter's small fee on top-ups).
  3. Recommended: give the key a credit limit when you make it (step 4) - it stops working once it has spent that much.
  4. Create a key on the API keys page and copy it - it's shown only once. It starts with sk-or-.
  5. Paste it below and press Connect.
