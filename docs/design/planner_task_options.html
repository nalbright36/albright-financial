Planner task: quick view and edit page

Same features as today, cleaned up. Eclipse styling, Planner lime.

Quick view · What opens when you tap a task

Every field is editable right here and saves automatically: tap the title to rename, tap a row (Date, Time, Repeat, Shared, Linked note) to change it, check off or add checklist items, edit notes. Existing attachments are listed but there's no Add files: that lives in the full editor.
